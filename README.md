# Learning Outcomes Insight Platform

An interactive education analytics prototype designed to help education teams explore student learning outcomes across years, grades, subjects, and school types.

This project was developed as part of the Flexera Round 1 Product Analytics task using ASER learning-outcome data.

## Problem

Learning-outcome data is often available as large tables or static reports, making it difficult for education teams to quickly identify:

- Changes in learning outcomes over time
- Differences between government and private schools
- Gaps between state and national performance
- Priority areas that need attention

The goal of this project is to make these insights easier to explore through an interactive product.

## Solution

The Learning Outcomes Insight Platform provides an interactive dashboard where users can select:

- Year
- Grade
- Subject (Reading / Arithmetic)

The selected filters dynamically update the displayed learning outcomes, comparisons, trends, and priority insights.

## Key Features

### 1. Interactive Filters
Users can filter the analysis by year, grade, and subject.

### 2. Learning Trends
The platform displays year-wise trends and compares national performance with Rajasthan.

### 3. School Type Comparison
Government and private school outcomes can be compared for the selected learning indicator.

### 4. Priority Insights
The platform highlights important learning gaps based on the selected data.

### 5. Data-driven Product View
The prototype is designed to help education teams move from raw learning data to actionable insights.
